## 핵심 인사이트

1. **단어 100개로 토큰 72.7% 커버** — 50% 커버는 단어 27개. 매우 가파른 절벽.
2. **한자 100자로 토큰 78.9% 커버** — 한자가 단어보다 학습 효율 압도적.
3. **HSK1 한자 300자 중 92%가 opus rank ≤1,000** — 거의 모두 회화에서 자주 등장.
4. **HSK4 한자급은 회화 빈도 낮음** — opus rank 200~500에서 본격 등장 (HSK4 학습자 기준: 회화는 단어 위주, 한자는 보조).
5. **HSK7-9 한자 1,200자 중 89%가 opus rank > 1,500** — 학술/문어 한자, 회화에서 거의 안 씀.
6. **회화 핵심 절벽**: 단어 rank 1,353 / 2,423 (log-slope 가장 가파른 두 점). 1,353 = Tier B 끝, 2,423 = 회화 핵심 어휘 끝.
