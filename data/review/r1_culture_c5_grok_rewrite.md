1 B: 嗨早！吃了没呀？ / Hāi zǎo! Chī le méi ya? / 하이 굿모닝! 밥 먹었니야?
초안보다 더 채팅스럽게 ‘嗨’를 넣고 吗→没, 呀로 끝맺어 실제 위챗 톤으로 바꿈

2 A: 吃了吃了！面包鸡蛋牛奶。 / Chī le chī le! Miànbāo jīdàn niúnǎi. / 먹었어 먹었어! 빵 계란 우유.
반복으로 리듬을 주고 쉼표 없이 붙여 써서 보고하는 느낌이 더 진지하게 과장됨

3 B: 哈哈中午也报一下？ / Hāhā zhōngwǔ yě bào yīxià? / ㅋㅋ 점심도 보고해 줄래?
‘呢’ 대신 ‘也报一下’로 바꿔 메뉴 보고를 계속 시키며 장난을 더함

4 A: 米饭鱼汤还有苹果🍎 / Mǐfàn yú tāng hái yǒu píngguǒ 🍎 / 밥 생선 국 그리고 사과🍎
이모지를 붙여 채팅 느낌을 살리고 문장을 더 짧게 붙임

5 B: 苹果谁买的？👀 / Píngguǒ shéi mǎi de? 👀 / 사과 누가 산 거야?👀
‘다 말 안 해도 돼’를 버리고 갑자기 질투 모드로 전환해 카오스를 터뜨림

6 A: 啊？自己买的……你在意？ / À? Zìjǐ mǎi de…… nǐ zài yì? / 어? 내가 산 건데…… 신경 쓰여?
설명 대신 말끝을 흐리며 먼저 훅을 던지고 오해를 키움

7 B: 没有啦就问问嘛。 / Méiyǒu la jiù wènwen ma. / 아니야 그냥 물어본 거야.
인사 설명을 짧게 변명으로 바꿔 당황한 티를 냄

8 A: ……那你呢？吃了没？ / …… Nà nǐ ne? Chī le méi? / ……그럼 너는? 먹었니?
반문하면서 여운을 남기고 吗→没로 맞춤
