1 A: 你好，我订了房啊。 / Nǐ hǎo, wǒ dìng le fáng a. / 안녕하세요, 저 방 예약했거든요. / ‘有预订’ 대신 구어 ‘订了房啊’로 리듬과 자연스러움 살림

2 B: 好呀，护照给我呗。 / Hǎo ya, hùzhào gěi wǒ bei. / 네, 여권 좀 주세요. / ‘请给我’ 대신 ‘给我呗’로 20대 직원 말투로 가볍게

3 A: 给你看下。 / Gěi nǐ kàn xià. / 여기 보여드릴게요. / ‘给您’을 ‘给你看下’로 바꿔 더 구어적이고 덜 딱딱하게

4 B: 哦，你是明天的。 / Ó, nǐ shì míngtiān de. / 아, 손님은 내일이에요. / ‘您的房间……是明天的’를 짧게 ‘你是明天的’로 압축, 말끝 여운

5 A: 明天？！我今天要住！ / Míngtiān?! Wǒ jīntiān yào zhù! / 내일?! 저 오늘 묵어야 해요! / 질문형 대신 당황한 단정으로 바꿔 카오스 폭발 시작

6 B: 今天就剩蜜月房。 / Jīntiān jiù shèng mìyuè fáng. / 오늘은 허니문 룸만 남았어요. / ‘只有一间了……是新婚房’을 ‘就剩蜜月房’으로 더 직설·리듬 있게

7 A: 蜜月房？我一个人…… / Mìyuè fáng? Wǒ yí ge rén…… / 허니문 룸? 저 혼자인데…… / ‘也可以吗’ 대신 말이 흐려지게 해 당황+설렘 여운으로 심쿵 포인트

8 B: 一个人也浪漫啊！ / Yí ge rén yě làngmàn a! / 혼자도 로맨틱하지! / ‘可以！送花和蛋糕’를 직원이 먼저 장난스럽게 훅 들어오는 한 줄로 바꿔 카오스·재미·심쿵 동시 달성
