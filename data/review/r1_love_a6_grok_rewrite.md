1 B: 号码给我呗？ / Hào mǎ gěi wǒ bei? / 번호 좀 줘봐? / 정중 의문문을 빼고 입자 ‘呗’로 길거리에서 바로 던지는 가벼운 요청으로 바꿈
2 A: 行啊！……没电了。 / Xíng a! …… Méi diàn le. / 좋아! ……나갔어. / ‘可以’를 더 구어적인 ‘行啊’로 바꾸고 당황을 짧게 터뜨림
3 B: 没事，写你手上。 / Méi shì, xiě nǐ shǒu shàng. / 괜찮아, 네 손에 쓸게. / 설명 없이 바로 행동으로 들어가는 능동적 말투로 교체
4 A: 好痒……快点！ / Hǎo yǎng…… kuài diǎn! / 간지러워…… 빨리! / 문장을 더 쪼개 리듬감 있게 만들어 웃음 포인트를 키움
5 B: 别动！下雨了——花了！ / Bié dòng! Xià yǔ le—— huā le! / 움직이지 마! 비 온다——번졌어! / 비와 글자 번짐을 한 호흡에 겹쳐 상황이 한꺼번에 터지게 만듦
6 A: 完了完了，号码没了！ / Wán le wán le, hào mǎ méi le! / 망했다 망했다, 번호 없어졌어! / 반복으로 당황을 과장해 재미와 카오스를 동시에 살림
7 B: 那……明天七点，我等你。 / Nà…… míng tiān qī diǎn, wǒ děng nǐ. / 그럼…… 내일 7시, 내가 기다릴게. / 말끝을 흐리고 ‘我等你’를 앞에 둬 여운과 심쿵을 더 강하게 남김
