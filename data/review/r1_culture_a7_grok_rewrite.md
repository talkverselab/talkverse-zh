1 A: 爷爷，给你啊！ / Yéye, gěi nǐ a! / 할아버지, 드릴게요! / 초안의 설명형 ‘这是我的礼物’를 버리고 그냥 건네는 말투로 바꿈

2 B: 等等，打开看！ / Děngděng, dǎkāi kàn! / 잠깐, 열어봐! / ‘里面是什么’의 질문 대신 직접 열어보라는 구어로 바꿈

3 A: 钟，超好看的。 / Zhōng, chāo hǎokàn de. / 시계, 완전 예뻐. / ‘一个钟。很好看吧’의 문장 구조를 깨고 감탄 위주로 바꿈

4 B: 钟？不行不行！ / Zhōng? Bùxíng bùxíng! / 시계? 안 돼 안 돼! / 초안의 설명 대신 즉각 패닉하는 반복으로 카오스 시작

5 A: 为啥？很贵的！ / Wèishá? Hěn guì de! / 왜? 엄청 비싼데! / ‘为什么’를 구어 ‘为啥’로, 방어하는 톤으로 바꿈

6 B: 送钟……不想再见。 / Sòng zhōng…… bù xiǎng zàijiàn. / 시계 주면…… 작별하기 싫어. / 초안의 설명 대신 말끝을 흐리며 마음을 드러내는 심쿵 라인으로 바꿈

7 A: 那叫手表吧。 / Nà jiào shǒubiǎo ba. / 그럼 손목시계라고 할게. / ‘我说是手表’의 질문형을 단정·제안형으로 바꿈

8 B: 晚了，爷爷打开了。 / Wǎn le, yéye dǎkāi le. / 늦었어, 할아버지 여셨어. / ‘已经打开了……他在笑’의 관찰을 패닉·결과 보고로 바꿈

추천 표현: 别送钟 / bié sòng zhōng / 시계는 주지 마

送钟像送终 / sòng zhōng xiàng sòngzhōng / 시계 선물은 작별 인사 같아
