2 B: 为啥啊？我家。 / Wèishá a? Wǒ jiā. / 왜? 내 집인데. / 교과서 '为什么'를 실제 20대 구어 '为啥啊'로 바꿈
3 A: 完了！蛋糕掉了！ / Wán le! Dàngāo diào le! / 망했다! 케이크 떨어졌어! / '等一下' 설명 빼고 패닉 반복으로 상황 바로 악화
4 B: 你没事吧？进！ / Nǐ méi shì ba? Jìn! / 너 괜찮아? 들어간다! / 단순 진입을 부상 오해로 바꿔 턴4에서 오해·꼬임 폭발
5 A: 生日快乐……乱死。 / Shēngrì kuàilè…… luàn sǐ. / 생일 축하해…… 개판이야. / 정리된 '有点乱'을 강한 구어와 말끝 흐림으로 변경
6 B: 哈哈蛋糕在头上！ / Hāha dàngāo zài tóu shang! / 하하 케이크 머리에! / 웃음을 더 직접 지적하는 킥 대사로 재작성
7 A: 别笑……我好紧张。 / Bié xiào…… wǒ hǎo jǐnzhāng. / 웃지 마…… 나 완전 긴장했어. / 사과 대신 여성 먼저 긴장 고백으로 심쿵 훅
8 B: 没事。有你最好。 / Méi shì. Yǒu nǐ zuì hǎo. / 괜찮아. 너 있어서 최고야. / '最好的生日'를 리듬 있는 마음 한 줄로 되치기
