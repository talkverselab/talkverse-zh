1 B: 来玩！石头剪刀布！又输？ / Lái wán! Shítou jiǎndāo bù! Yòu shū? / 하자! 가위바위보! 또 졌어? / 초안의 긴 물음을 짧은 놀람으로 바꿔 즉흥적 시작.
2 A: 三次了耶！你请！ / Sān cì le yē! Nǐ qǐng! / 세 번째야! 네가 쏴! / '你请客'을 더 짧고 직설적인 구어로.
3 B: 再来！最后一次啊！ / Zài lái! Zuìhòu yí cì a! / 한 번 더! 마지막이야! / 설명을 외침 두 개로 쪼개 다급함 추가.
4 A: 好！石头剪刀布！ / Hǎo! Shítou jiǎndāo bù! / 좋아! 가위바위보! / 망설임 빼고 바로 수락해 페이스 빠르게.
5 B: 又输哈哈，我钱没了…… / Yòu shū hāha, wǒ qián méi le…… / 또 졌어 하하, 내 돈 다 갔어…… / '我的钱'을 과장된 파산 느낌으로 바꿔 웃음 키움.
6 A: 你总输，是想请我吗？ / Nǐ zǒng shū, shì xiǎng qǐng wǒ ma? / 너 맨날 지네, 나 사주고 싶은 거 아냐? / 관찰을 직접 질문으로 바꿔 오해·카오스 폭발, 여성 쪽 훅.
7 B: 对啊……一直想请你。 / Duì a…… yīzhí xiǎng qǐng nǐ. / 응…… 계속 사주고 싶었어. / 설명을 수줍은 인정으로 줄여 여운·심쿵 남김.
