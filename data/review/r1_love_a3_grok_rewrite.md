1 B: 嘿，分你一只。 / Hēi, fēn nǐ yī zhī. / 야, 한쪽 줄게. / 이어폰을 직접 건네며 더 적극적이고 친근하게 시작해서 첫 훅을 세게 함.
2 A: 嗯？啥歌啊？ / Ńg? Shá gē a? / 응? 무슨 노래야? / ‘啥’와 ‘啊’로 더 짧고 구어적인 젊은 말투로 바꿈.
3 B: 你听啊。好听不？ / Nǐ tīng a. Hǎotīng bu? / 들어 봐. 좋아? / ‘听听’ 대신 짧은 ‘你听啊’와 캐주얼한 ‘好听不’로 리듬을 살림.
4 A: 好听！叫啥名？ / Hǎotīng! Jiào shá míng? / 좋다! 이름 뭐야? / ‘叫什么’를 ‘叫啥名’으로 더 짧고 킥 있게 압축.
5 B: 没名儿。我写的。 / Méi míngr. Wǒ xiě de. / 이름 없어. 내가 쓴 거야. / ‘没有名字’를 구어체 ‘没名儿’로 바꿔 더 자연스럽고 짧게.
6 A: 真的？那我第一！ / Zhēn de? Nà wǒ dì yī! / 진짜? 그럼 내가 첫 번째! / 기쁨을 바로 폭발시켜 도서관에서 소리 지를 상황을 만들고 카오스를 터뜨림.
7 B: 别喊……就你一个。 / Bié hǎn…… jiù nǐ yī ge. / 소리 지르지 마…… 너 하나야. / 도서관 소리 지른 걸 지적하며 상황을 꼬고, 말끝을 흐려 심쿵으로 마무리.
