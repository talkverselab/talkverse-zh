[UXZ01] 중국어 학습 앱 「중국어유니버스」(Flutter, 공개 저장소 https://github.com/talkverselab/talkverse-zh )의 **아이패드 가로(720pt 이상) UX/UI 시안 1개 + 그림 1장**을 부탁합니다. 이 방은 중국어 앱 전용이고, 앞으로 한 번에 시안 1개씩 주고받습니다.

## 지금 앱(최신 커밋 c77ae36)
- 자매 앱(일본어)에서 확정한 「만화책 읽기형」 구조를 그대로 옮겼습니다: 탭 4개 배우기·복습·탐색·나(lib/screens/main_screen.dart), 넓은 화면 = 왼쪽 레일 + 왼쪽 목록 + 오른쪽 내용(lib/core/pane.dart). 편 화면 = 리더(lib/widgets/episode_play_pane.dart): 넓은 화면은 왼쪽 「대화 스크립트」(번호·화자 점·중국어·병음·한글 독음·한국어·🔊) + 오른쪽 큰 장면 컷(현재 대사 말풍선) + 캡션, 하단 고정 ▶ 재생·진행 슬라이더·속도·자막 칩(中文 고정/병음/독음/한국어).
- 톤: 흰 바탕 · 남색 글자 #0A2540 · 인디고 #635BFF(선택·현재 턴) · 구리 #B77548 → 황갈 #C19E6D 포인트 · 선 #E6EBF1 · 보조 #6B7C93. 색은 유지, 배치·형태는 바꿔도 됩니다.
- **중국어만의 것**(이번 시안의 핵심):
  1. 성조: 병음 위 성조 색(1성 빨강 · 2성 주황 · 3성 초록 · 4성 파랑 · 경성 회색)과 「성조 연습」·「4성 매트릭스」 메뉴가 있습니다. 회화 리더 안에서 성조를 어떻게 보여 줄지(색 병음 / 성조 곡선 / 끄고 켜기).
  2. 한자 팝업(lib/widgets/selectable_hanzi.dart): 회화 속 한자 탭 → 간체 자형·병음·뜻·한국 한자음·발음부(声旁)·외우는 팁·어원·글자 움직임 그림·HSK 쓰기 범위.
  3. 「한자 배우기」(20자 단계 → 글자 정보 → 문제)와 새 「패밀리 한자」(lib/screens/family_hanzi_screen.dart — 소리 부품이 같은 글자 가족, 예: 青→清·情·请·晴, 병음 성조 색, 같은 소리 글자는 구리 테두리). 중국어는 소리 가족이 일본어보다 뚜렷해서 이것을 앱의 차별점으로 키우고 싶습니다.
  4. 레벨: 빈도 절벽 R0 왕초보 · R1 초보(앞으로 채움) · R2 · R3 · R4. 지금 회화 129편은 R2~R4.
- 성과 표시 원칙: 센다 = 편 완주·라이트너 단계·핵심 표현 맞음·팝업으로 본 글자 수·빈도 커버율("내가 아는 단어로 일상 중국어의 약 N%") / 안 센다 = 앱 오픈·스트릭·포인트·순위.

## 이번 답에 넣을 것(시안 1개)
1. 콘셉트 한 문단 — 위 구조는 유지하고, **성조·한자 팝업·한자 배우기·패밀리 한자**를 중국어 앱답게 어떻게 녹일지.
2. **그림 1장**(이미지 생성): 아이패드 가로 한 프레임(4:3, 태블릿 1개). 회화 리더 화면 — 왼쪽 레일 + 왼쪽 스크립트(중국어·성조 색 병음·독음·한국어, 현재 턴 인디고) + 오른쪽 장면 컷(첨부한 우리 단어 그림 3장의 톤 **그대로**: 파스텔 배경, 부드러운 펠트·점토 인형 둘이 찻집에서 대화, 그림 안 글자 없음) + 한 글자를 탭해 열린 한자 팝업(발음부 가족 줄 포함). 이미지는 이 1장만.
3. 텍스트 레이아웃(ASCII 박스): 회화 리더 / 한자 팝업 / 패밀리 한자 / 「나」 탭 성과. 폰 세로는 한 줄씩.
4. 핵심 컴포넌트 명세(성조 표시, 팝업, 패밀리 한자 카드), 타이포·간격·모션, 다크 모드 한 줄, Flutter 구현 메모(코드 없이: 바꿀 파일·위젯 트리).
