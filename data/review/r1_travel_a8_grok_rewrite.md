1 B: 扫一下就能开了。 / Sǎo yí xià jiù néng kāi le. / 한번 찍으면 열려. / ‘就能骑很简单’ 설명투를 빼고 실제 앱 말투 ‘开了’로 바꿈
2 A: 我扫了，没反应。 / Wǒ sǎo le, méi fǎnyìng. / 찍었는데, 반응 없어. / ‘没开啊’를 앱에서 진짜 쓰는 ‘没反应’으로 교체
3 B: 再扫一次呗。 / Zài sǎo yí cì bei. / 한번 더 찍어봐. / ‘再扫一次’에 20대 입자 ‘呗’를 붙여 구어체로
4 A: 还是卡着！你先走。 / Háishi kǎ zhe! Nǐ xiān zǒu. / 그래도 걸려! 너 먼저 가. / ‘不行你先走吧’를 ‘卡着’로 구체화해 작은 말실수 씨앗을 심음
5 B: 卡什么卡？上来我带你。 / Kǎ shénme kǎ? Shàng lái wǒ dài nǐ. / 무슨 걸려? 올라와 내가 태워줄게. / ‘不走上来’를 ‘卡什么卡’ 되치기로 바꿔 4턴 오해를 폭발시킴
6 A: 两个人挤得下吗？ / Liǎng ge rén jǐ de xià ma? / 두 사람 끼어 탈 수 있어? / ‘可以吗’를 실제 걱정 ‘挤得下’로 바꿔 웃음 포인트 추가
7 B: 抓紧我别松手。 / Zhuā jǐn wǒ bié sōng shǒu. / 꽉 잡고 손 놓지 마. / 문장을 붙여 리듬감 있게 만들고 암기 포인트로
8 A: ……再跟你骑一圈？ / …… Zài gēn nǐ qí yì quān? / ……너랑 한 바퀴 더? / ‘再骑一圈’에 ‘跟你’를 넣어 여운·심쿵을 여성 A가 먼저 던지게
추천 표현: 卡什么卡 / Kǎ shénme kǎ / 무슨 걸려 (절대 안 됨)
