1 B: 就你一个啊？ / Jiù nǐ yí ge a? / 너 혼자야? / ‘吗’ 질문 대신 ‘就…啊’로 길거리 말투 바꾸며 접근감 강화
2 A: 啥？完全听不见！ / Shá? Wánquán tīng bú jiàn! / 뭐? 완전 안 들려! / ‘什么·太吵了’를 ‘啥·完全听不见’로 바꿔 클럽 소음 속 실제 반응
3 B: 我说就你一个！ / Wǒ shuō jiù nǐ yí ge! / 내 말 너 혼자라고! / 장황한 반복·부호 빼고 짧게 외치며 상황 압박 상승
4 A: 喜欢我？真的假的？！ / Xǐhuan wǒ? Zhēn de jiǎ de?! / 나 좋아해? 진짜야?! / 오해를 더 크게 점프시키고 ‘真的假的’로 카오스·웃음 폭발
5 B: 谁说了？！听错了！ / Shéi shuō le?! Tīng cuò le! / 누가 그랬어?! 잘못 들은 거야! / 단순 부정 대신 ‘谁说了’ 되치기로 당황+재미 추가
6 A: 啊……我乱听的。 / À…… wǒ luàn tīng de. / 아…… 내가 잘못 들은 거. / ‘对不起’ 정중함 빼고 자기 탓 캐주얼로 리듬 살림
7 B: 不过……挺好听。 / Búguò…… tǐng hǎotīng. / 근데…… 꽤 듣기 좋네. / ‘也没有错’를 더 여운 있는 ‘挺好听’으로 바꿔 여성 주도 심쿵
