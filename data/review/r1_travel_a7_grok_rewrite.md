1 B: 停！这是我的箱子 / Tíng! Zhè shì wǒ de xiāngzi. / 멈춰! 이건 내 캐리어야 / 초안의 느린 ‘等一下’를 급하게 가로채는 ‘停！’으로 바꿔 실제 공항에서 딱 하는 말투로
2 A: 才不是 我的也这样 / Cái bú shì wǒ de yě zhèyàng. / 절대 아냐 내 것도 이렇다고 / 초안의 단순 부정·소유 주장을 빼고 ‘才不是+也这样’로 똑같이 생겼음을 한 번에 자연스럽게
3 B: 打开不就知道了 / Dǎkāi bù jiù zhīdào le. / 열면 바로 알잖아 / 초안의 제안형 ‘那打开看看？’를 당연한 듯이 던지는 구어로 바꿔 주도권 잡기
4 A: 好啊……啊这啥啊 / Hǎo a…… à zhè shá a. / 그래…… 어 이게 뭐야 / 초안의 교과서 ‘这是什么’를 실제 젊은이들 말 ‘这啥啊’로 바꾸고 말끝 흐리기
5 B: 别看了 衣服而已 / Bié kàn le yīfu éryǐ. / 보지 마 옷일 뿐이야 / 초안의 당황하며 설명하는 ‘是……我的衣服’를 짧게 자르고 ‘而已’로 얼버무리게
6 A: 好可爱你也挺可爱 / Hǎo kě'ài nǐ yě tǐng kě'ài. / 너무 귀여워 너도 꽤 귀여워 / 초안의 단순 색깔·곰 지적을 귀여움으로 연결해 카오스와 심쿵을 동시에 터지게 (여성 먼저 훅)
7 B: 不是啊妹妹的衣服 / Bú shì a mèimei de yīfu. / 아니야 여동생 옷이야 / 초안의 ‘真的！’ 강조를 빼고 더 급하게 부정하며 상황 꼬이게
8 A: 你没有妹妹啊…… / Nǐ méiyǒu mèimei a…… / 너 여동생 없잖아…… / 초안의 단정형 외침을 말끝 흐리는 ‘……’로 바꿔 여운과 심쿵 남기기
