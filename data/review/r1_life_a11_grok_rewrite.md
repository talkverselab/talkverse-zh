1 B: 您好，外卖到了，几号楼呀？ / Nín hǎo, wàimài dào le, jǐ hào lóu ya? / 안녕하세요, 배달 도착했어요, 몇 동이에요? / 초안의 딱딱한 질문 끝을 ‘呀’로 바꿔 길거리·전화 말투로 더 가볍게 만듦
2 A: 六号楼六楼。 / Liù hào lóu liù lóu. / 6동 6층이요. / 쉼표를 없애고 붙여 말해서 당황한 초보 말투로 더 급하게 바꿈
3 B: 六号没电梯，我爬。 / Liù hào méi diàntī, wǒ pá. / 6동 엘리베이터 없네요, 제가 올라갈게요. / ‘好’ 대신 직접 행동 말을 넣어 기사 말투를 더 생생하게 만듦
4 A: 哎呀哥，看错了，八号！ / Āiyā gē, kàn cuò le, bā hào! / 아 기사님, 잘못 봤어요, 8동! / ‘是八号楼’를 짧게 자르고 ‘哎呀’를 앞에 넣어 말실수 느낌을 더 살림
5 B: 八号也没？我爬三次了！ / Bā hào yě méi? Wǒ pá sān cì le! / 8동도 없어요? 나 세 번이나 올라갔다고! / 단순 엘리베이터 언급을 이미 세 번 올라간 폭로로 바꿔 여기서 상황이 확 터지게 만듦
6 A: 对不起对不起！真八号！ / Duìbuqǐ duìbuqǐ! Zhēn bā hào! / 죄송해요 죄송해요! 진짜 8동! / ‘这次真的是’를 빼고 사과를 두 번 반복해 더 당황하고 리듬 있게 바꿈
7 B: 到了。您……九号楼？ / Dào le. Nín…… jiǔ hào lóu? / 도착했어요. 고객님…… 9동? / ‘是…吧’를 빼고 짧게 끊어서 의심과 웃음을 더 강하게 만듦
8 A: 我下去拿……辛苦你了。 / Wǒ xiàqù ná…… xīnkǔ nǐ le. / 제가 내려갈게요…… 수고하셨어요. / 별점 대신 말끝을 흐리며 고마움을 직접 말해 여운과 심쿵을 넣음
