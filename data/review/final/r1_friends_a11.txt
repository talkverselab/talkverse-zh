1 B: 来，先跑十分钟热身。 / Lái, xiān pǎo shí fēnzhōng rèshēn. / 자, 먼저 10분 뛰면서 몸 풀어. / 热身 = 준비운동
2 A: 十分钟？我已经废了。 / Shí fēnzhōng? Wǒ yǐjīng fèi le. / 10분? 나 벌써 끝났어. / 废了 = 망가졌다·녹초가 됐다
3 B: 才两分钟就废了？ / Cái liǎng fēnzhōng jiù fèi le? / 겨우 2분인데 끝났다고? / 才 = 겨우
4 A: 啊，机器自己加速了！ / À, jīqì zìjǐ jiāsù le! / 아, 기계가 혼자 빨라져! / 加速 = 가속하다
5 B: 你按着加速键呢！ / Nǐ ànzhe jiāsù jiàn ne! / 너 가속 버튼 누르고 있잖아! / 按着 = 누르고 있다
6 A: 停不下来啊！救命！ / Tíng bu xiàlai a! Jiùmìng! / 안 멈춰! 살려 줘! / 停不下来 = 멈출 수 없다
7 B: 拉红绳！……别怕，我在。 / Lā hóng shéng! …… Bié pà, wǒ zài. / 빨간 줄 당겨! ……겁내지 마, 내가 있어. / 别怕 = 겁내지 마
8 A: 明天我真不来了…… / Míngtiān wǒ zhēn bù lái le…… / 내일 나 진짜 안 와…… / 不来了 = 안 오겠다
