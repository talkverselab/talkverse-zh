1 B: 奶奶给你做了最爱的！ / Nǎinai gěi nǐ zuò le zuì ài de! / 할머니가 네가 제일 좋아하는 거 해 주셨어! / 最爱 = 제일 좋아하는
2 A: 太好啦！我先放筷子。 / Tài hǎo la! Wǒ xiān fàng kuàizi. / 좋아! 젓가락부터 놓고. / 筷子 = 젓가락
3 B: 别插！快拿开！ / Bié chā! Kuài ná kāi! / 꽂지 마! 빨리 빼! / 插 = 꽂다
4 A: 啊？我做错了？ / À? Wǒ zuò cuò le? / 어? 내가 잘못했어? / 做错 = 잘못하다
5 B: 那是给去世的人的。 / Nà shì gěi qùshì de rén de. / 그건 돌아가신 분께 하는 거야. / 去世 = 세상을 떠나다
6 A: 啊！奶奶，对不起！ / À! Nǎinai, duìbuqǐ! / 아! 할머니, 죄송해요! / 对不起 = 죄송해요
7 B: 没事啦，奶奶在笑呢。 / Méishì la, nǎinai zài xiào ne. / 괜찮아, 할머니 웃고 계셔. / 在~呢 = ~하는 중이야
8 A: 放平了……以后你教我吧。 / Fàng píng le…… yǐhòu nǐ jiāo wǒ ba. / 눕혔어…… 앞으로 네가 가르쳐 줘. / 教 = 가르치다
