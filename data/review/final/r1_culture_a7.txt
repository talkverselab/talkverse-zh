1 A: 爷爷，这是给您的！ / Yéye, zhè shì gěi nín de! / 할아버지, 이거 드리는 거예요! / 给您的 = 당신께 드리는 것
2 B: 等等，里面是什么？ / Děngděng, lǐmiàn shì shénme? / 잠깐, 안에 뭐야? / 里面 = 안
3 A: 一个钟，超好看的。 / Yí ge zhōng, chāo hǎokàn de. / 시계, 완전 예뻐. / 钟 = 시계
4 B: 钟？不行不行！ / Zhōng? Bù xíng bù xíng! / 시계? 안 돼 안 돼! / 不行 = 안 된다
5 A: 为什么？很贵的！ / Wèishénme? Hěn guì de! / 왜? 엄청 비싼 건데! / 贵 = 비싸다
6 B: 送钟就是……说再见。 / Sòng zhōng jiù shì…… shuō zàijiàn. / 시계를 준다는 건…… 작별 인사야. / 送钟 = 시계 선물(送终 「임종」과 발음이 같음)
7 A: 那……叫手表吧？ / Nà…… jiào shǒubiǎo ba? / 그럼…… 손목시계라고 할까? / 手表 = 손목시계
8 B: 晚了，爷爷打开了……他在笑！ / Wǎn le, yéye dǎkāi le…… tā zài xiào! / 늦었어, 할아버지가 여셨어…… 웃고 계셔! / 在笑 = 웃고 있다
