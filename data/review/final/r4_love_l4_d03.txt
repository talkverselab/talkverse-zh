1 B: 帅哥，请问一下。 / Shuàigē, qǐngwèn yíxià. / 잘생긴 오빠, 뭐 좀 물어볼게. / ‘帅哥’ + ‘请问一下’ / polite
2 A: 嗯？什么事？ / Ńg? Shénme shì? / 응? 무슨 일이야? / ‘什么事’는 ‘무슨 일이야’ / surprised
3 B: 附近有好喝的咖啡吗？ / Fùjìn yǒu hǎohē de kāfēi ma? / 근처에 맛있는 카페 있어? / 존현문 ‘有’ + ‘好喝的’ / polite
4 A: 有，前面就有一家。 / Yǒu, qiánmiàn jiù yǒu yì jiā. / 있지, 바로 앞에 하나 있어. / ‘就’ 강조 + ‘家’ 양사 / polite
5 B: 能带我去吗？ / Néng dài wǒ qù ma? / 나 좀 데려다줄 수 있어? / ‘带…去’ + ‘能’ / shy
6 A: 行，反正我顺路。 / Xíng, fǎnzhèng wǒ shùnlù. / 그래, 어차피 나도 가는 길이야. / ‘反正’ + ‘顺路’ / cheerful
7 B: 其实是想跟你认识。 / Qíshí shì xiǎng gēn nǐ rènshi. / 사실은 너랑 친해지고 싶었어. / ‘其实’ + ‘是想’ / shy
8 A: 哈哈，那一起喝一杯吧。 / Hāha, nà yìqǐ hē yì bēi ba. / 하하, 그럼 같이 한잔하자. / ‘那’ + ‘吧’ 제안 / amused
