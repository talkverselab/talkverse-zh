1 B: 我妈问你还要不要？ / Wǒ mā wèn nǐ hái yào bu yào? / 우리 엄마가 더 먹을 거냐고 물으셔. / 还要 = 더 원하다
2 A: 不用不用，我饱了。 / Bú yòng bú yòng, wǒ bǎo le. / 아니에요 아니에요, 배불러요. / 饱 = 배부르다
3 B: 真的假的？你眼睛在看菜。 / Zhēn de jiǎ de? Nǐ yǎnjing zài kàn cài. / 진짜야? 너 눈은 음식 보고 있잖아. / 真的假的 = 진짜야 가짜야
4 A: 被你发现了……还想吃。 / Bèi nǐ fāxiàn le…… hái xiǎng chī. / 들켰네…… 더 먹고 싶어. / 被~发现 = ~에게 들키다
5 B: 那刚才为什么说不要？ / Nà gāngcái wèishénme shuō bú yào? / 그럼 아까 왜 안 먹는다고 했어? / 刚才 = 아까
6 A: 韩国人要先拒绝三次…… / Hánguó rén yào xiān jùjué sān cì…… / 한국 사람은 먼저 세 번 사양해야…… / 拒绝 = 거절하다
7 B: 我妈已经收走了。 / Wǒ mā yǐjīng shōu zǒu le. / 엄마가 벌써 치우셨어. / 收走 = 치우다
8 A: 阿姨！我要！我要！我要！ / Āyí! Wǒ yào! Wǒ yào! Wǒ yào! / 어머니! 먹을게요! 먹을게요! 먹을게요! / 阿姨 = 아주머니
