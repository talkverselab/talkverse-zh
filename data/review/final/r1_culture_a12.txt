1 B: 今年是你本命年啊。 / Jīnnián shì nǐ běnmìngnián a. / 올해가 네 본명년이네. / 本命年 = 띠해(12년마다 돌아오는 자기 띠의 해)
2 A: 本命年？什么意思？ / Běnmìngnián? Shénme yìsi? / 본명년? 무슨 뜻이야? / 意思 = 뜻
3 B: 你属什么呀？ / Nǐ shǔ shénme ya? / 너 무슨 띠야? / 属 = ~띠이다
4 A: 属龙啊，怎么了？ / Shǔ lóng a, zěnme le? / 용띠야, 왜? / 龙 = 용
5 B: 龙年要穿红的哦。 / Lóng nián yào chuān hóng de o. / 용의 해엔 빨간 걸 입어야 해. / 红的 = 빨간 것
6 A: 红的？穿什么红的？ / Hóng de? Chuān shénme hóng de? / 빨간 거? 무슨 빨간 거? / 什么 = 무슨
7 B: 袜子，内裤……给，我买了。 / Wàzi, nèikù…… gěi, wǒ mǎi le. / 양말, 속옷…… 자, 내가 샀어. / 内裤 = 속옷(팬티)
8 A: ……你买了我的内裤？ / …… Nǐ mǎi le wǒ de nèikù? / ……네가 내 속옷을 샀다고? / 买了 = 샀다
