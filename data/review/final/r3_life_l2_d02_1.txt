1 A: 我还在公司呢。 / Wǒ hái zài gōngsī ne. / 나 아직 회사야. / 在…呢 = 아직 ~에 있다 / sad
2 B: 又加班啊？ / Yòu jiābān a? / 또 야근이야? / 又 = 또 (반복) / worried
3 A: 王哥给了我一堆活儿。 / Wáng gē gěi le wǒ yī duī huór. / 왕 형이 일을 한 무더기 줬어. / 堆 = 무더기, 活儿 = 일 / annoyed
4 B: 可怜的小宝贝。 / Kělián de xiǎo bǎobèi. / 불쌍한 우리 아기. / 的 = 형용사 수식 / teasing
5 A: 我快饿死了。 / Wǒ kuài è sǐ le. / 배고파 죽기 직전이야. / 快…了 = 곧 ~한다, 死了 = 과장 / sad
6 B: 奶茶给你点好了，看门口。 / Nǎichá gěi nǐ diǎn hǎo le, kàn ménkǒu. / 밀크티 시켜놨어, 입구 봐봐. / 给 = ~에게 해 주다 / gentle
7 A: 真的假的？ / Zhēn de jiǎ de? / 진짜야 가짜야? / 真的假的 = 진짜? / surprised
8 A: 来了！你太好了吧！ / Lái le! Nǐ tài hǎo le ba! / 왔다! 너 진짜 최고다! / 太…了 = 너무 ~하다, 吧 = 감탄 / excited
