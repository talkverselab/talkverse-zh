1 B: 羊肉、牛肉、蔬菜，够吗？ / Yángròu, niúròu, shūcài, gòu ma? / 양고기, 소고기, 야채, 충분해요? / 够은 ‘충분하다’. / neutral
2 A: 再来一个土豆，我爱土豆。 / Zài lái yí ge tǔdòu, wǒ ài tǔdòu. / 감자 하나 추가요, 저 감자 사랑해요. / 再来一个은 ‘하나 더’ 주문 표현. / cheerful
3 B: 好，再来两瓶可乐。 / Hǎo, zài lái liǎng píng kělè. / 네, 콜라도 두 병 추가요. / 两瓶은 양사 瓶. / polite
4 A: 哇，锅来了！好香！ / Wa, guō lái le! Hǎo xiāng! / 와, 냄비 나왔다! 냄새 좋다! / 来了은 ‘나왔다’, 好香은 감탄. / excited
5 B: 小心，烫！ / Xiǎoxīn, tàng! / 조심해요, 뜨거워요! / 小心은 ‘조심’, 烫은 ‘뜨겁다’. / worried
6 A: 没事，我不怕烫……啊，烫！ / Méishì, wǒ bú pà tàng…… A, tàng! / 괜찮아요, 저 뜨거운 거 안 무서워요… 앗, 뜨거! / 没事은 ‘괜찮다’. / cheerful
7 B: 哈哈哈，我说了吧！ / Hāhāhā, wǒ shuō le ba! / 하하하, 내가 말했잖아요! / 我说了吧은 ‘거봐’. / amused
8 A: 给我一杯水，快！ / Gěi wǒ yì bēi shuǐ, kuài! / 물 한 잔 주세요, 빨리빨리! / 给我은 ‘给我’, 一杯은 양사 杯. / flustered
