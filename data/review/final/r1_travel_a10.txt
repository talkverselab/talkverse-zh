1 B: 你上铺，我中铺。 / Nǐ shàng pù, wǒ zhōng pù. / 너 위칸, 나 중간칸. / 铺 = (열차) 침대
2 A: 好，我上去了啊。 / Hǎo, wǒ shàngqu le a. / 응, 올라간다. / 上去 = 올라가다
3 B: 停停停！对面那个！ / Tíng tíng tíng! Duìmiàn nàge! / 멈춰 멈춰! 맞은편 거! / 对面 = 맞은편
4 A: 啊啊啊，大叔对不起！ / À à à, dàshū duìbuqǐ! / 아아아, 아저씨 죄송해요! / 大叔 = 아저씨
5 B: 下来下来！他睡着呢！ / Xiàlai xiàlai! Tā shuìzhe ne! / 내려와 내려와! 자고 계셔! / 睡着 = 자고 있다
6 A: 完了，鞋掉你那了！ / Wán le, xié diào nǐ nà le! / 망했다, 신발 네 쪽으로 떨어졌어! / 掉 = 떨어지다
7 B: 砸脸上了……好重。 / Zá liǎn shang le…… hǎo zhòng. / 얼굴에 떨어졌어…… 무겁네. / 砸 = 내리치다
8 A: 对不起……你还好吗？ / Duìbuqǐ…… nǐ hái hǎo ma? / 미안…… 괜찮아? / 还好 = 괜찮다
