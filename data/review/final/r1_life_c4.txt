1 A: 完了！钥匙没了，进不去！ / Wán le! Yàoshi méi le, jìn bu qù! / 망했다! 열쇠가 없어, 못 들어가! / 进不去 = 들어갈 수 없다
2 B: 包里找过没？ / Bāo li zhǎo guo méi? / 가방 안은 찾아봤어? / 找过 = 찾아봤다
3 A: 找过了，没有！ / Zhǎo guo le, méiyǒu! / 찾아봤어, 없어! / 没有 = 없다
4 B: 外套口袋看看？ / Wàitào kǒudai kànkan? / 외투 주머니는? / 口袋 = 주머니
5 A: 也没有！冻死了！ / Yě méiyǒu! Dòng sǐ le! / 거기도 없어! 얼어 죽겠어! / 冻死了 = 얼어 죽겠다
6 B: 裤子口袋，快掏！ / Kùzi kǒudai, kuài tāo! / 바지 주머니, 빨리 뒤져! / 掏 = 꺼내다·뒤지다
7 A: 有了……你怎么知道？ / Yǒu le…… nǐ zěnme zhīdào? / 있다…… 어떻게 알았어? / 怎么知道 = 어떻게 알아
8 B: 因为你每次都这样～ / Yīnwèi nǐ měi cì dōu zhèyàng～ / 넌 매번 이러니까～ / 每次 = 매번
