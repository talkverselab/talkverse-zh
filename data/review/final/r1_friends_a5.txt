1 B: 帮我看会儿狗呗，我进去买瓶水。 / Bāng wǒ kān huìr gǒu bei, wǒ jìnqù mǎi píng shuǐ. / 개 좀 잠깐 봐 줘, 들어가서 물 한 병 사 올게. / 看会儿 = 잠깐 보다, 呗 = 가볍게 부탁 / cheerful
2 A: 好呀，没问题。它叫什么名字？ / Hǎo ya, méi wèntí. Tā jiào shénme míngzi? / 좋아, 문제없어. 이름이 뭐야? / 叫什么名字 = 이름이 뭐야 / cheerful
3 B: 叫豆豆。别给它吃东西啊。 / Jiào Dòudou. Bié gěi tā chī dōngxi a. / 더우더우야. 아무것도 먹이지 마. / 别…… = ~하지 마 / gentle
4 A: 豆豆，坐下！……它怎么不听我的？ / Dòudou, zuòxià! ……Tā zěnme bù tīng wǒ de? / 더우더우, 앉아! ……왜 내 말을 안 듣지? / 听……的 = ~의 말을 듣다 / flustered
5 B: 我回来了。它乖不乖？ / Wǒ huílái le. Tā guāi bu guāi? / 나 왔어. 얌전히 있었어? / 乖 = 얌전하다 / cheerful
6 A: 乖什么呀，它一直往店里跑。 / Guāi shénme ya, tā yìzhí wǎng diàn lǐ pǎo. / 얌전하긴, 계속 가게 안으로 뛰어가려고 했어. / 一直 = 계속 / tsukkomi
7 B: 它在找我呢。你得说"坐"，它听不懂"坐下"。 / Tā zài zhǎo wǒ ne. Nǐ děi shuō "zuò", tā tīng bù dǒng "zuòxià". / 나 찾은 거야. "앉아(坐下)" 말고 "앉(坐)"이라고 해야 알아들어. / 得 = ~해야 한다 / amused
8 A: 豆豆，坐！……真的坐了！ / Dòudou, zuò! ……Zhēn de zuò le! / 더우더우, 앉! ……진짜 앉았어! / 真的 = 진짜로 / surprised
