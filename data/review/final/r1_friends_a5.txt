1 B: 帮我看会儿狗呗。 / Bāng wǒ kàn huìr gǒu bei. / 잠깐만 개 좀 봐 줘. / 看会儿 = 잠깐 보다, 呗 = 가볍게 부탁
2 A: 好呀！一只狗，没问题。 / Hǎo ya! Yì zhī gǒu, méi wèntí. / 좋아! 한 마리쯤이야. / 没问题 = 문제없어
3 B: 不是一只，是五只！ / Bú shì yì zhī, shì wǔ zhī! / 한 마리가 아니라, 다섯 마리! / 只 = 마리(양사)
4 A: 五只？！你逗我呢？ / Wǔ zhī?! Nǐ dòu wǒ ne? / 다섯?! 나 놀리는 거야? / 逗 = 놀리다
5 B: 邻居的，拜托啦！ / Línjū de, bàituō la! / 이웃집 개야, 부탁해! / 拜托 = 부탁해
6 A: 你不在，我怎么办？ / Nǐ bú zài, wǒ zěnme bàn? / 너 없으면 나 어떡해? / 怎么办 = 어떡해
7 B: 对了，还有三只猫！ / Duì le, hái yǒu sān zhī māo! / 아 맞다, 고양이도 세 마리! / 对了 = 아 참
8 A: 你给我回来啊！ / Nǐ gěi wǒ huílai a! / 야, 당장 돌아와! / 给我~ = 당장 ~해(명령 강조)
