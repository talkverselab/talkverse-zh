1 B: 咱俩换手机一天，敢吗？ / Zán liǎ huàn shǒujī yì tiān, gǎn ma? / 우리 하루 폰 바꾸기, 할 수 있겠어? / 咱俩 = 우리 둘, 敢 = 감히 ~하다
2 A: 敢啊！现在换！ / Gǎn a! Xiànzài huàn! / 하지! 지금 바꿔! / 换 = 바꾸다
3 B: 完了……手机响了。 / Wán le…… shǒujī xiǎng le. / 망했다…… 폰 울린다. / 响 = 울리다
4 A: 是你妈！我接了啊！ / Shì nǐ mā! Wǒ jiē le a! / 너희 엄마야! 나 받는다! / 接 = (전화를) 받다
5 B: 别接！快挂！ / Bié jiē! Kuài guà! / 받지 마! 빨리 끊어! / 挂 = 끊다

7 B: 别说了！快挂掉！ / Bié shuō le! Kuài guà diào! / 말하지 마! 빨리 끊어! / 挂掉 = 끊어 버리다
