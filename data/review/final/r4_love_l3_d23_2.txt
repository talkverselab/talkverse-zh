1 A: 到时候，我有话要问你爸。 / Dàoshíhou, wǒ yǒu huà yào wèn nǐ bà. / 그때 가서, 아버님께 여쭤볼 말이 하나 있어. / ‘到时候’ + ‘有+명사+동사’ / shy
2 B: 问我爸呀？问什么？ / Wèn wǒ bà ya? Wèn shénme? / 아빠한테? 뭘 물어보는데? / 어기조사 ‘呀’ / surprised
3 A: 秘密。跟你的手有关系。 / Mìmì. Gēn nǐ de shǒu yǒu guānxi. / 비밀이야. 네 손과 관계가 있지. / ‘跟…有关系’ / teasing
4 B: 我的手？你要送我戒指？ / Wǒ de shǒu? Nǐ yào sòng wǒ jièzhi? / 내 손? 너 설마 나한테 반지…… / ‘要’ + 이중목적어 ‘送’ / flustered
5 A: 嘘，说出来就没效了。 / Xū, shuō chūlái jiù méi xiào le. / 쉿, 말해버리면 효력이 없어진대. / ‘出来’ + ‘就’ / teasing
6 B: 傻瓜，那我慢慢等着。 / Shǎguā, nà wǒ mànman děngzhe. / 바보, 그럼 난 천천히 기다릴게. / ‘慢慢’ 중첩 + ‘着’ 지속 / shy
7 A: 嗯，答案很快就知道了。 / Ńg, dá'àn hěn kuài jiù zhīdào le. / 응, 답은 곧 밝혀질 거야. /  / gentle
8 B: 好期待那天啊。 / Hǎo qīdài nà tiān a. / 그날이 너무 기다려져. /  / gentle
