1 B: 我打篮球超厉害！ / Wǒ dǎ lánqiú chāo lìhai! / 나 농구 완전 잘해! / 厉害 = 대단하다
2 A: 真的假的？给我看看！ / Zhēn de jiǎ de? Gěi wǒ kànkan! / 진짜야 가짜야? 보여 줘 봐! / 真的假的 = 진짜야 가짜야
3 B: 看好了啊——哎呦，球飞了！ / Kàn hǎo le a—— āiyō, qiú fēi le! / 잘 봐—— 아악, 공 날아갔어! / 飞 = 날다
4 A: 球去哪儿了？！ / Qiú qù nǎr le?! / 공 어디 갔어?! / 去哪儿 = 어디 가다
5 B: 掉那辆车上了。 / Diào nà liàng chē shang le. / 저 차 위에 떨어졌어. / 掉 = 떨어지다
6 A: 车开走了！赶紧追！ / Chē kāi zǒu le! Gǎnjǐn zhuī! / 차 출발했어! 빨리 쫓아! / 赶紧 = 빨리
7 B: 算了，买个新的得了。 / Suàn le, mǎi ge xīn de dé le. / 됐어, 새 거 사면 되지. / 算了 = 됐어
8 A: 你不是超厉害吗？笑死我了。 / Nǐ bú shì chāo lìhai ma? Xiào sǐ wǒ le. / 너 완전 잘한다며? 웃겨 죽겠네. / 笑死 = 웃겨 죽다
