1 B: 今天我给你做饭！ / Jīntiān wǒ gěi nǐ zuò fàn! / 오늘은 내가 밥 해 줄게! / 给你做饭 = 너에게 밥을 해 주다
2 A: 真的？你会做饭吗？ / Zhēn de? Nǐ huì zuò fàn ma? / 진짜? 너 요리할 줄 알아? / 会 = ~할 줄 안다
3 B: 会啊！你坐着等。 / Huì a! Nǐ zuòzhe děng. / 할 줄 알지! 앉아서 기다려. / 坐着 = 앉은 채로
4 A: 小丽……怎么冒烟了？ / Xiǎolì…… zěnme mào yān le? / 샤오리…… 왜 연기가 나? / 冒烟 = 연기가 나다
5 B: 没事没事！新做法！ / Méishì méishì! Xīn zuòfǎ! / 괜찮아 괜찮아! 새 요리법이야! / 做法 = 만드는 법
6 A: 邻居都来敲门了！ / Línjū dōu lái qiāo mén le! / 이웃들까지 문 두드리러 왔어! / 敲门 = 노크하다
7 B: 出去吃吧……我只想跟你吃饭。 / Chūqu chī ba…… wǒ zhǐ xiǎng gēn nǐ chī fàn. / 나가서 먹자…… 그냥 너랑 밥 먹고 싶었어. / 只 = 그냥 ~만
8 A: 那以后天天出去吃！ / Nà yǐhòu tiāntiān chūqu chī! / 그럼 앞으로 매일 나가서 먹자! / 天天 = 매일
