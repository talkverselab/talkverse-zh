1 B: 咱俩换手机一天，敢吗？ / Zán liǎ huàn shǒujī yì tiān, gǎn ma? / 우리 하루 폰 바꿔, 할래? / “敢不敢”를 “敢吗”로 줄이고 “咱俩”를 넣어 더 툭 던지는 친구 말투로 바꿈
2 A: 敢啊！现在换！ / Gǎn a! Xiànzài huàn! / 하지! 지금 바꿔! / 바로 행동으로 이어지는 짧은 되치기로 재미를 키움
3 B: 完了……手机响了。 / Wán le…… shǒujī xiǎng le. / 망했다…… 폰 울리네. / “完了” 한 마디로 순식간에 당황이 폭발하도록 만듦
4 A: 是你妈！我接了！ / Shì nǐ mā! Wǒ jiē le! / 너희 엄마야! 나 받았어! / 이미 받은 것처럼 말해 상황을 더 꼬이게 함
5 B: 别接啊快挂！ / Bié jiē a kuài guà! / 받지 마 빨리 끊어! / 두 마디를 붙여  panic이 한꺼번에 터지게 함
6 A: 阿姨好，我是女朋友。 / Āyí hǎo, wǒ shì nǚ péngyou. / 어머님 안녕, 저 여자친구예요. / 물어본 걸 스스로 인정해 여성 쪽에서 먼저 훅 들어가며 카오스·심쿵을 동시에 만듦
7 B: 别说了快挂掉！ / Bié shuō le kuài guà diào! / 말하지 마 빨리 끊어! / “그 말 하지 마”를 넣어 오해가 더 커지는 되치기로 바꿈
8 A: 她说周末吃饭，我去吗？ / Tā shuō zhōumò chī fàn, wǒ qù ma? / 주말에 밥 먹자고, 나 갈까? / 끝에 흐리는 “我去吗”로 마음을 살짝 들키는 여운을 남김
추천 표현: 敢吗 / gǎn ma / 할래? ; 我去吗 / wǒ qù ma / 나 갈까?
