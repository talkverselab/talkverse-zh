1 B: 嘿，来啦，吃点啥？ / Hēi, lái la, chī diǎn shá? / 헤이, 왔어, 뭐 좀 먹을래? / 교과서 '你好想吃什么' 대신 20대 길거리·가게에서 실제로 쓰는 가벼운 인사로 바꿈
2 A: 这个，那个也来。 / Zhège, nàge yě lái. / 이거랑, 저것도 주세요. / '还有这个'의 번역투를 빼고 손가락으로 찍는 느낌의 짧은 말로 바꿈
3 B: 辣的要不要？ / Là de yào bú yào? / 맵게 할래 말래? / '要辣的吗'의 딱딱한 질문형을 실제 종업원이 던지는 짧은 확인으로 바꿈
4 A: 要！啊——不要辣！ / Yào! A—— bú yào là! / 할래! 아—— 맵지 않게! / 초안의 설명하는 '我说错了'를 없애고 말실수가 바로 터지는 카오스로 바꿈
5 B: 好，超辣上！ / Hǎo, chāo là shàng! / 좋아, 초맵으로 올려! / '特别辣'의 정중한 확인을 재미로 되치며 상황을 더 키우는 킥 대사로 바꿈
6 A: 别别别，零辣！ / Bié bié bié, líng là! / 안 돼 안 돼, 제로 맵게! / '一点都不要'를 더 급하고 리듬 있게 바꿔 당황이 커지게 함
7 B: 哈哈好，不辣。水来，你这样…… / Hāha hǎo, bù là. Shuǐ lái, nǐ zhèyàng…… / 하하 좋아, 안 맵게. 물 왔어, 너 이렇게…… / 서비스 멘트 대신 말끝을 흐리며 여운을 남기는 심쿵 한 줄로 바꿈
