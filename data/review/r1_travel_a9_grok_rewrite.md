1 A: 师傅，阳光酒店。 / Shīfu, Yángguāng Jiǔdiàn. / 기사님, 양광 호텔이요. / "去"를 빼고 목적지만 던져서 더 즉흥적이고 길거리 말투
2 B: 哪个阳光？三个。 / Nǎge Yángguāng? Sān ge. / 어느 양광이요? 세 개. / 호텔을 빼고 짧게 되물어서 당황을 바로 키움
3 A: 三个？！大的那个！ / Sān ge?! Dà de nàge! / 세 개요?! 큰 거요! / 놀람을 더 세게 터뜨리고 설명 없이 바로 찍음
4 B: 都挺大，你挑一个。 / Dōu tǐng dà, nǐ tiāo yí ge. / 다 꽤 커요, 하나 골라요. / "选" 대신 "挑"로 더 구어적으로 선택을 떠넘김
5 A: 有泳池的……帮我选？ / Yǒu yǒngchí de…… bāng wǒ xuǎn? / 수영장 있는 거…… 골라 주세요? / 말끝을 흐리며 부탁으로 바꿔 심쿵과 혼란이 동시에 폭발
6 B: 都有泳池，选哪个？ / Dōu yǒu yǒngchí, xuǎn nǎge? / 다 수영장 있어요, 어느 거요? / 똑같은 답을 되치기해서 상황이 더 꼬이게 만듦
7 A: 看订单！是这个。 / Kàn dìngdān! Shì zhège. / 주문 봐요! 이거예요. / 급하게 들이밀며 당황을 더 노골적으로
8 B: 哦，这在别的城市。 / Ò, zhè zài bié de chéngshì. / 아, 이건 다른 도시네요. / "这个在另一个"를 더 짧고 직접적으로 바꿔 반전을 세게
