1 B: 今晚这身，好看不？ / Jīn wǎn zhè shēn, hǎo kàn bù? / 오늘 이 옷, 예뻐? / 초안의 설명투 ‘今天穿这个，好看吗’를 바로 사진 찍고 던지는 짧고 캐주얼한 말로 바꿈
2 A: 好看！真的好看！ / Hǎo kàn! Zhēn de hǎo kàn! / 예뻐! 진짜 예뻐! / 초안의 반복 칭찬을 더 감탄 섞인 리듬으로 바꿔 과잉 반응의 씨앗을 심음
3 B: 你咋发了那么多心？ / Nǐ zǎ fā le nà me duō xīn? / 왜 하트 그렇게 많이 보냈어? / 초안의 ‘五十个表情’ 설명을 ‘咋’ 줄임말로 바꿔 실제 채팅처럼 갑자기 꼬이게 만듦
4 A: 不是我！手机坏了！ / Bú shì wǒ! Shǒu jī huài le! / 내가 아니야! 폰이 고장 났어! / 초안 순서를 뒤집어 당황이 먼저 튀어나오게 해 카오스를 키움
5 B: 全是爱心，喜欢我？ / Quán shì ài xīn, xǐ huān wǒ? / 전부 하트인데, 나 좋아하는 거야? / 초안의 단순 확인을 직접 물어 심쿵과 오해를 한 번에 터뜨림
6 A: ……不是，手机发的。 / …… Bú shì, shǒu jī fā de. / …아니야, 폰이 보낸 거야. / 초안의 변명을 더 짧게 끊어서 말실수처럼 보이게 함
7 B: 明天带手机来见我。 / Míng tiān dài shǒu jī lái jiàn wǒ. / 내일 폰 데리고 나 보러 와. / 초안의 ‘那’를 빼고 더 직접 불러서 여운과 장난을 동시에 남김
