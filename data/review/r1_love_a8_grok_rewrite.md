1 B: 我们去坐那个呀！ / Wǒmen qù zuò nàge ya! / 우리 저거 타러 가자야! / 초안의 단순한 ‘坐那个吧’를 ‘去坐…呀’로 바꿔 실제 길에서 손으로 가리키며 재촉하는 말투로 만듦
2 A: 你不怕高的吗？ / Nǐ bú pà gāo de ma? / 너 높은 거 안 무서워? / ‘那个？’를 빼고 ‘的吗’를 넣어 확인하는 구어 질문으로 완전히 바꿈
3 B: 谁怕了！……就一点。 / Shéi pà le! …… jiù yìdiǎn. / 누가 무서워! …그냥 쪼끔. / ‘不怕！一点点怕’를 ‘谁怕了’ 반박 후 인정으로 바꿔 더 강하고 웃긴 말투로
4 A: 那你干嘛要坐啊？ / Nà nǐ gànmá yào zuò a? / 그럼 왜 타자는 건데? / ‘为什么’를 ‘干嘛…啊’로 바꿔 친구끼리 되치기하는 일상 말투로
5 B: 因为想跟你一起嘛！别问了快上！ / Yīnwèi xiǎng gēn nǐ yìqǐ ma! Bié wèn le kuài shàng! / 너랑 같이 있고 싶어서 말이야! 묻지 말고 빨리 타! / 초안은 그냥 ‘别问了’였는데, 여기서 ‘想跟你一起’를 말실수처럼 뱉어 턴 5에서 카오스와 심쿵을 터뜨림
6 A: 到顶了！因为我吗？ / Dào dǐng le! Yīnwèi wǒ ma? / 꼭대기다! 나 때문에야? / ‘到最上面了！你看！’를 바꿔 방금 말을 바로 되받아 놀리는 킥으로 재미를 키움
7 B: 别动啊！手给我…… / Bié dòng a! Shǒu gěi wǒ…… / 움직이지 마! 손 줘…… / ‘别动！手……给我’에 ‘啊’와 말끝 흐림을 더해 당황하면서도 먼저 훅 들어오는 느낌으로
8 A: 下去了还拉吗？ / Xiàqù le hái lā ma? / 내려가서도 잡고 있을 거야? / ‘下去以后……还拉着吗’를 더 짧고 직접적으로 바꿔 여운을 남김
추천 표현: 怕高 / Pà gāo / 높은 게 무섭다; 手给我 / Shǒu gěi wǒ / 손 줘
