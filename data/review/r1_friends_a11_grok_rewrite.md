1 B: 来，先跑十分钟热身。 / Lái, xiān pǎo shí fēnzhōng rèshēn. / 와, 먼저 10분 뛰어 몸 풀어. / 초안의 명령조를 ‘来’로 시작하는 친구 유도형으로 바꿔 현장감 살림
2 A: 十分钟？我已经废了。 / Shí fēnzhōng? Wǒ yǐjīng fèi le. / 10분? 나 이미 끝났어. / ‘快不行了’를 젊은이들이 자주 쓰는 과장 ‘废了’로 완전히 교체
3 B: 才两分钟就废了？ / Cái liǎng fēnzhōng jiù fèi le? / 겨우 2분인데 끝났다고? / 단순 정정을 되치기 반문으로 바꿔 웃음 포인트 추가
4 A: 啊机器自己加速了！ / Ā jīqì zìjǐ jiāsù le! / 아 기계가 혼자 빨라져! / ‘越来越快’를 ‘自己加速’로 바꿔 통제 불능 카오스를 턴4에서 폭발
5 B: 你按着加速呢！ / Nǐ àn zhe jiāsù ne! / 너 가속 누르고 있잖아! / 설명투를 현재진행 직격으로 바꿔 즉시성과 리얼함 강화
6 A: 停不下来啊救命！ / Tíng bù xiàlái a jiùmìng! / 안 멈춰 아 살려줘! / 여러 문장을 한 호흡으로 합쳐 패닉을 더 세고 리듬 있게
7 B: 拉红绳……别怕我在。 / Lā hóng shéng…… bié pà wǒ zài. / 빨간 줄 당겨…… 겁내지 마, 나 있어. / 단순 지시를 말끝 흐림과 안심 말로 바꿔 여성이 먼저 훅 들어오는 심쿵 삽입
8 A: 明天我真不来了…… / Míngtiān wǒ zhēn bù lái le…… / 내일 나 진짜 안 와…… / 단호한 선언을 말끝 흐림으로 바꿔 여운과 약한 모습 강조
추천 표현: 救命啊 / Jiùmìng a / 살려 줘 ; 不行了 / Bù xíng le / 안 돼
